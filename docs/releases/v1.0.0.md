# ContractLedger AI v1.0.0

**Release date:** 2026-09-02
**Release status:** Portfolio-ready baseline

ContractLedger AI v1.0.0 closes the roadmap as a focused, human-in-the-loop contract-operations portfolio system. The release connects legacy intake, AI-assisted document review, human verification, approval controls, executed registration, amendment lineage, obligations, source-aware exports, AI evaluation, permissions, and audit evidence.

## Release evidence

- Seven completed lifecycle releases from v0.2 through v0.8.
- Fifteen versioned fictional evaluation documents with field-level ground truth and explicit limitations.
- Seven workspace roles and thirteen server-enforced permissions.
- Deterministic reset inventory: seven contracts, eight suppliers, three intakes, five obligations, five approval records, and one import preview.
- Two consecutive reset responses are byte-for-byte equivalent after pinning the demo reset timestamp.
- All 15 demo files are visibly fictional and use only reserved example email domains; all nine seeded document links open.
- Amendment, approval, obligation, import, review-package, calendar, authorization, and invalid-input smoke paths pass.
- The repository quality gate contains the ordered phase gate, Definition of Done gate, 101 tests, lint, TypeScript, and production build.

See [V1_SMOKE_TEST.md](V1_SMOKE_TEST.md) for the executable and interface checklist and [v1.0-release-evidence.json](v1.0-release-evidence.json) for the bounded inventory and version record.

## Baseline commands

```bash
npm run dev -- --host 127.0.0.1
npm run check:baseline
npm run quality
```

## Known boundaries

- This release is an operational portfolio demonstration, not legal advice or an autonomous legal decision-maker.
- All suppliers, agreements, people, signatures, addresses, values, and outcomes in the fixture set are fictional.
- The release does not claim real-company time savings, legal outcomes, production-scale duplicate precision, or active external delivery.
- The reset check validates the local D1/R2-backed environment. Hosted deployment health remains an environment-specific operational check.
- Repository gates verify declared evidence structure and presence; reviewers remain responsible for evidence quality and historical command provenance.
