## Visual rules

- Navy `#0d2638`, mint `#76dbc3`, paper `#f5f4ee`.
- Keep at least one quarter of the mark width clear around the mark when placing it independently.
- Use the dark-background wordmark on dark surfaces. Never stretch artwork.
- Keep the fictional portfolio context with promotional copy.
- The cards in the graphics illustrate a workflow; they are not product screenshots or measured business outcomes.

## Regeneration

Run `npm ci`, then `npm run brand:generate`. Sharp is pinned as a development dependency. Masters and exports are generated by `scripts/generate-brand-assets.mjs`. Text uses Arial/Helvetica; Chinese export requires a CJK system font. Exports committed here were visually reviewed on macOS. Recheck typography when regenerating on a different operating system.

## SEO implementation

- `lib/seo.ts`: common copy, canonical-origin resolution, Open Graph/Twitter cards and structured data.
- `app/layout.tsx`: favicon family, manifest, creator and theme colour.
- `app/page.tsx`: root canonical; `login`, `auth_error` and `view` query URLs are `noindex, follow`. UTM-only links remain indexable with a clean canonical.
- `/about`: public, server-rendered overview with one H1, feature descriptions, FAQ and product links. It requires no workspace authentication.
- `/robots.txt`: allows public pages/assets and excludes APIs and fictional source-document paths. Noindex query URLs remain crawlable so their meta directive can be read.
- `/sitemap.xml`: only the root and `/about`; no invented modification timestamps.
- `/manifest.webmanifest`: browser-mode identity; no offline or PWA functionality is claimed.
- JSON-LD describes the website, creator, application and overview. No prices, reviews, ratings or unsupported rich-result promises are included.

`SITE_URL` must be the intended public origin. Missing/blank/invalid values fall back to the project's existing domain, `https://contractledger.selinaq.com`. Explicit HTTP localhost URLs remain supported for isolated development. A private or staging deployment needs its own deployment-level indexing policy; this public portfolio configuration is not an access-control mechanism.

Run `npm run check:seo -- http://127.0.0.1:3011 https://contractledger.selinaq.com` against a running preview. The second argument is the expected public canonical origin, independent of the preview address. See [QA.md](QA.md) for executed verification.

## Publication handoff

1. Deploy these changes through the existing release workflow when deployment is authorized.
2. Rerun `npm run check:seo -- https://contractledger.selinaq.com https://contractledger.selinaq.com` against production.
3. In the site owner's verified Google Search Console property, submit `/sitemap.xml` and inspect `/about`. Verification tokens must come from that account; none have been invented.
4. Upload the GitHub image in repository settings and the LinkedIn cover on the intended profile. These are supplied files, not automatically applied account settings.
5. Refresh cached share previews using the platform's inspection tools where available. Recheck the live URL before posting the supplied copy.

Implementation references: [Google favicon guidance](https://developers.google.com/search/docs/appearance/favicon-in-search), [Google site names](https://developers.google.com/search/docs/appearance/site-names), [Next metadata routes](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/robots). Search ranking and preview refresh timing are controlled by the receiving services.
